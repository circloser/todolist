# 업무나침반 (Work Compass)

연도/팀 업무 진행 보드

여러 연도와 팀이 각자 업무 진행 상황을 함께 확인하는 웹사이트입니다.
연도/팀별 보드를 개인 계정과 부서장 승인으로 운영하며, 목록 중심의 업무
관리, 담당자 필터, 정렬, 드래그 순서 변경, 지도, 간트, 월간 보고서를
지원합니다.

주요 기능:

- 화면 탭: 대시보드(첫 화면) · 목록 · 업무일정 · 회의록 · 업무일지 · 지도 · 간트
- 업무일정: 보드 전체가 공유하는 달력, 두 달 나란히 보기(한 달 보기 전환),
  분류·참석 구성원·알림 시점, 공휴일 표시, 업무 마감 함께 보기
- 회의록: 구성원 기반 참석자(1명 이상 필수)·외부 참석자·안건·내용·결정 사항·
  후속 조치, 미참석자의 "회의 내용을 확인했습니다" 확인 기록, A4 인쇄
- 알림: 일정 시작 전·새 일정·새 회의록 팝업과 브라우저 알림, 알림 패널(오늘·내일
  일정, 확인할 회의록, 내 후속 조치, 마감 임박·지연), 평일 오전 웹훅에 오늘 일정 포함
- 개인 아이디/비밀번호 로그인, 보드 가입 신청과 부서장 승인
- 권한: 구성원은 본인 담당 업무·본인 업무일지만 수정, 부서장은 전체 업무
  관리·배정과 업무일지 승인/반려
- 구성원 관리(가입 승인, 부서장 지정, 계정 연결/해제, 비활성화)
- 업무일지(하루 1건, 보드 활동 불러오기, 승인 대기함, CSV)
- 업무일지 모아보기: 일간 카드 · 주간 표(구성원×요일) · 월간 달력 · 목록
- 업무일지 리포트: 개인 상세 보고서(결재란·요약·관련 업무·특이사항·일자별),
  팀 요약표, 연간 보고서(월별 작성률 그래프·월별 현황·팀 연간 개요), A4 인쇄/PDF
- 부서장 운영 옵션: 일지 열람 범위, 승인 절차, 승인 일지 잠금, 지난 날짜 작성
  기간, 구성원 업무 등록·삭제 허용
- 새 연도 생성 시 전년도 같은 팀 데이터 복사 옵션
- 업무 위계(대분류/중분류/소분류)별 목록 관리
- 단계별 순차 완료 체크 및 세부 체크리스트
- 담당자 필터, 색상, 드래그앤드롭 순서 변경
- 지도 핀, 간트 차트, 월간 보고서, 기안문 양식함

기본 진행 템플릿:

1. 계획(초안)
2. 견적
3. 계획 결재
4. 구매 요청
5. 계약 체결
6. 착수
7. 과업 진행(25%)
8. 과업 진행(50%)
9. 과업 진행(75%)
10. 과업 진행(100%)
11. 완료계 접수
12. 검수
13. 대금 지급 요청
14. 결과 보고

## 실행

```powershell
npm.cmd install
npm.cmd run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 빌드

```powershell
npm.cmd run build
```
