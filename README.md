# 연도/팀 업무 진행 보드

여러 연도와 팀이 각자 업무 진행 상황을 함께 확인하는 웹사이트입니다.
연도/팀별 보드를 만들고 암호로 접근을 제한할 수 있으며, 목록 중심의 업무
관리, 담당자 필터, 정렬, 드래그 순서 변경, 지도, 간트, 월간 보고서를
지원합니다.

주요 기능:

- 중앙 랜딩 화면에서 연도/팀 선택 후 암호 입장
- 연도/팀 보드 생성 및 암호 기반 접근
- 새 연도 생성 시 전년도 같은 팀 데이터 복사 옵션
- 업무 위계(대분류/중분류/소분류)별 목록 관리
- 단계별 순차 완료 체크 및 세부 체크리스트
- 담당자 필터, 색상, 드래그앤드롭 순서 변경
- 지도 핀, 간트 차트, 월간 보고서, 기안문 양식함

기본 진행 템플릿:

1. 계획(초안)
2. 견적
3. 계획 결재
4. 구매 요청
5. 계약 체결
6. 착수
7. 과업 진행(25%)
8. 과업 진행(50%)
9. 과업 진행(75%)
10. 과업 진행(100%)
11. 완료계 접수
12. 검수
13. 대금 지급 요청
14. 결과 보고

## 실행

```powershell
npm.cmd install
npm.cmd run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 빌드

```powershell
npm.cmd run build
```
